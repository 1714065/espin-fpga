WHAT IT DOES

把组合优化接入日常工作流

FPGA-Ising 是通过可编程硬件执行优化搜索的加速组件。Agent 提供对话入口，帮助用户组织输入、调用设备并解释结果。适用于路线候选选择、资源分配、排程等可建模为 QUBO / Ising 的问题；具体业务模型仍需验证约束和效果。

01用户与 Agent描述目标，提交原题
02设备调用服务检查权限、身份与状态
03上位机 → FPGA执行搜索，返回候选
04核验 → 对话结果复算目标值，记录来源

SQA 为模拟量子退火，不代表光量子计算机。最新聊天示例使用 K=0 固定参数，属于独立副本配置，不能据此证明非零耦合 SQA 的质量优势。

如何解读这组数字
  • 每档一道稠密 Wishart 固定实例，16 副本、STEP=64、MC=16，共 1024 次扫描；相同初态、随机流与输出，双方各重放 3 次取中位数。
  • 参数与随机输入选自已有搜索记录并冻结。三次重放用于计时，不是独立新题或最优成功率实验；搜索最佳配置的成本没有计入内核时间。
  • CPU 为同规则、同固定点语义的单核 C 对照。FPGA 时间按原始周期数与归档 100 MHz 配置换算，没有独立外测频率证据。
  • 不包含 Agent、矩阵上传、排队和全链核验。不代表相对最强多核 CPU、GPU 或光量子设备的加速。
  • F009 与 00D 版本不同，不能替代最新 Agent 通道的规模验收。N=1024 的 K=0；N=8192 的 K 为钳位常数，不能解释为普遍量子退火优势。

HELP & TROUBLESHOOTING

常见问题

可以直接把业务描述交给 Agent 吗？

可以先整理目标、变量与约束。执行前需要明确数学模型，并核对业务含义。低能量不自动代表路线合法、排程可执行或业务最优。

显示“未就绪”或“未配置”怎么办？

保存提示，请服务人员检查本次入口、设备登记与上位机。未提交就没有本轮硬件结果；需要继续讲解时，可以明确切换到本说明书的历史实测记录。

网络断开后，要再发一次题目吗？

先保留平台任务号，在原会话查询。确认未受理，或明确需要新计算后再提交。断线不等于没有执行，关闭浏览器也不等于停止硬件。

“已完成”为什么还显示质量未知？

执行完成说明取得了结果；质量还需要可信参考目标或评价规则。目标值复算通过不能等同全局最优，未登记的业务检查也应显示未评估。

为什么小问题可能不如 CPU 快？

设备调用、数据传输、队列和核验有固定开销。小题计算很短，这些开销可能占主导；本说明书保留了软件更快的结果。应在目标业务题上对比端到端效果。

自动选参、超大题、手机操作都能用吗？

以交付通道的实际能力和验收范围为准。00D 本次聊天演示覆盖固定参数、小题和桌面；旧版自动选参、历史 8192 内核实验与本次网页分开记录。说明书手机可读不等于聊天产品手机操作通过。
